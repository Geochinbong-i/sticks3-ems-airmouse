# StickS3 EMS Timer & Air Mouse

M5Stack **StickS3** (`ESP32-S3-PICO-1-N8R8`) 전용 경량 펌웨어입니다.  
구급대원 현장 처치용 **EMS 타이머**, **BLE / USB-C 에어마우스**, **자이로스코프 기반 에어 하프**를 제공합니다.

## 주요 기능

### 1. EMS TIMER (구급대원 타이머)
- **스톱워치 (`TIMER`)**: `HH:MM:SS` 표시, 일시정지/재개 지원.
- **에피네프린(EPI) 투여 간격 타이머**: 3분 / 4분 / 5분 설정 가능, 투여 횟수(`DOSE #N`) 자동 카운트.
  - 30초 이하 남으면 황색 경고, 0초 도달 시 적색 점멸 + 경고음, 이후 초과 시간(`+MM:SS`) 표시 및 15초마다 리마인더 알림.
- **바이탈/체크포인트 카운트다운 프리셋**: `OFF / 1m / 2m / 3m / 5m / 10m / 15m` 선택 가능.
- **이벤트 로그 (`VIEW LOGS`)**에 현장 이벤트를 최근 64건까지 기록합니다. 사건 시작 이후의 경과 시각은 타이머를 일시정지해도 계속 흐릅니다. 시계가 맞춰지면 기존 이벤트와 새 이벤트에 현지 절대 시각도 표시합니다. 다시 동기화하면 같은 시간 기준을 전체 타임라인에 적용합니다.
- 이벤트 태그는 `START`, `EPI #`, `SHOCK #`, `ROSC`, `VITAL`, `AIRWAY`, `IV`, `PAUSE`, `RESUME`입니다. 정맥로를 확보하면 `LOG IV`를 선택해 직접 기록합니다.
- 홈으로 이동해도 타이머와 로그는 계속 유지됩니다. 재부팅하거나 확인 창에서 `RESET`을 실행하면 현재 사건 기록이 지워집니다.

#### EMS 타이머 버튼 조작
- **대기(`EMS READY`) 상태**:
  - `A` 짧게: 프리셋 시간 변경 (`OFF` ~ `15m`)
  - `B` 짧게: **타이머 시작 (`START`)**
  - `B` 길게(0.65초): EPI 간격 변경 (`3m` / `4m` / `5m`)
- **실행(`EMS RUN` / `EMS PAUSE`) 상태**:
  - `A` 짧게: 하단 실행 버튼 선택 이동 (`LOG EPI` → `LOG SHOCK` → `LOG ROSC` → `LOG VITAL` → `LOG AIRWAY` → `LOG IV` → `PAUSE/RESUME` → `VIEW LOGS` → `RESET`)
  - `B` 짧게: 선택된 동작 실행 (기본값 `LOG EPI`)
  - `B` 길게(0.65초): 어느 메뉴가 선택되어 있어도 **즉시 `EPI` 투여 기록 및 간격 리셋**
  - `A` 길게(0.65초): 활성 알람음 해제 / 음소거 전환
  - `A + B` 길게(0.6초): 홈 메뉴로 복귀

### 2. AIR MOUSE (BLE & USB-C 자이로 에어마우스)
홈의 **AIR MOUSE**를 열고 **BLUETOOTH** 또는 **USB-C**를 선택합니다.
- **6축 IMU(BMI270) 자이로 기반 포인터**:
  - 진입 시 0.8초 자동 영점 보정 + 정지 상태 자동 드리프트 보정.
  - 미세 데드존 + 비선형 가속 곡선 + 서브픽셀 누적으로 정밀 클릭과 빠른 화면 이동을 동시에 지원.
- **두 가지 연결 방식**:
  - **BLE (`AIR MOUSE BLE`)**: 장치명 `StickS3 AirMouse` (Windows, macOS, Linux, Android, iOS 페어링).
  - **USB-C (`AIR MOUSE USB`)**: USB-C 케이블로 PC/태블릿에 직접 연결 시 표준 HID 마우스로 동작(드라이버 불필요).

#### 에어마우스 버튼 조작
- `A` 누르기/유지: **마우스 왼쪽 버튼 (LMB)** (클릭, 더블클릭, 드래그)
- `B` 짧게: **마우스 오른쪽 버튼 (RMB)**
- `B` 길게(0.3초 이상 유지): **스크롤 휠 모드** (손목을 위/아래로 기울여 스크롤)
- `A + B` 짧게: **포인터 일시정지 / 재개 (클러치)**
- `A + B` 길게(0.6초): 홈 메뉴로 복귀

### 3. AIR HARP

홈에서 **AIR HARP**를 열고 **SINGLE** 또는 **ARPEGGIO**를 선택합니다. 평소 연주 자세로 잠깐 멈추면 기준 자세를 잡습니다.

- **SINGLE**은 좌우로 반음씩, 상하로 음량 0–100%를 조절합니다. **ARPEGGIO**는 좌우로 으뜸음, 상하로 장조·자연단음계·펜타토닉을 선택해 자동으로 연주합니다. 조와 스케일 변경은 다음 박자에 적용합니다.
- **Settings → Air Harp**에서 회전 범위(좌우 각각 45°, 60°, 75°), 옥타브(2, 3, 4, 2–3, 2–4), A 버튼 방식을 고릅니다. HOLD는 누르는 동안, TOGGLE은 누를 때마다 연주를 켜거나 끕니다.
- **B**를 누르면 현재 자세를 다시 기준으로 잡습니다. **A+B**를 길게 누르면 홈으로 돌아갑니다.
- 화면이 자동으로 꺼지면 하프 소리와 자이로가 멈춥니다. EMS 알림이 발생하면 하프보다 우선합니다.

### 4. SETTINGS

Display, Time, Timers, Air Mouse, Air Harp, Sound, IR Remote, Device로 나뉩니다. **Display → Theme**에서 `DARK / LIGHT`를 고릅니다. A로 이동하고 B로 열거나 값을 바꿉니다. A+B를 길게 누르면 한 단계 뒤로 돌아갑니다. 바꾼 값은 자동 저장됩니다.

## 화면 자동 꺼짐과 부팅 시 시간 동기화

- **SETTINGS → Display → Screen Off**에서 `OFF / 30s / 1m / 3m` 중 하나를 선택합니다. 기본값은 `OFF`이며 설정은 재부팅 후에도 유지됩니다. A/B 입력이 없으면 화면이 꺼집니다. 처음 누른 A/B는 화면만 깨웁니다. 화면이 꺼져도 타이머와 HID 연결은 계속 동작하며, 새 EPI 또는 프리셋 알림이 화면을 깨웁니다.
- **핫스팟 / Wi-Fi**는 **SETTINGS → Time → Time Sync → 1. Wi-Fi AP Push**에서 등록합니다. 휴대폰으로 `StickS3-SYNC`에 연결해 `http://192.168.4.1`을 열고, 인터넷에 연결된 2.4GHz 핫스팟이나 Wi-Fi의 SSID와 암호를 저장합니다. 다음 부팅부터 핫스팟이 IP를 할당하면 `time.cloudflare.com`과 `pool.ntp.org`를 사용해 시간을 맞춥니다. 수동 Wi-Fi SNTP 화면에서는 IP 할당 실패와 NTP 응답 시간 초과를 구분해서 표시합니다.
- **아이폰 BLE**는 **SETTINGS → Time → Time Sync → 3. BLE Time Sync**에서 B를 누릅니다. StickS3에 BLE READY가 표시되면 아이폰 **설정 → Bluetooth**에서 StickS3-Time을 선택합니다. 이미 BLE 마우스로 페어링한 아이폰에서는 기존 기기 이름이 표시될 수 있습니다. 연결되면 StickS3가 암호화된 연결에서 아이폰의 Current Time Service를 읽고, 시각을 받으면 BLE TIME SYNCED!를 표시합니다.
- BLE 스캐너를 사용할 때는 Current Time Service (0x1805)의 Current Time (0x2A2B)에 현재 시간을 YYYY-MM-DD HH:MM:SS UTF-8 문자열로 쓸 수도 있습니다.
- BLE를 한 번 동기화하면 저장된 Wi-Fi가 없거나 SNTP가 실패한 부팅에서 이미 페어링된 호스트의 재접속을 최대 30초 기다립니다. 자동 동기화는 호스트가 CTS를 제공하거나 재접속 시 시간을 써 주는 앱을 실행할 때 동작합니다. BLE 호스트와 StickS3의 시간대는 동일하게 맞춥니다. 수동 BLE 검색과 Wi-Fi 설정 창은 각각 최대 2분간 열립니다. 부팅 중 홈에 Wi-Fi 또는 Bluetooth 아이콘이 표시되고, 시각이 준비되면 현지 시각으로 바뀝니다.
- **RTC**는 전원 차단 중에도 칩에 백업 전원이 공급되어야 시간이 흐릅니다. 펌웨어는 부팅 시 RX8130의 발진 정지 플래그를 확인하며, 시간이 유실됐으면 자동 동기화가 완료될 때까지 미설정으로 취급합니다. SIMPLE TIMER에서 시각을 기록하려면 먼저 시계가 설정되어 있어야 합니다. 보드에서 유지 여부를 확인하려면 동기화 후 USB를 분리하고 전원 버튼으로 종료한 뒤, Wi-Fi와 BLE를 끈 상태로 다시 켜서 시각과 시리얼 로그(`RTC restored` 또는 `RX8130 clock lost or unreadable`)를 확인합니다. [StickS3 문서](https://docs.m5stack.com/en/core/StickS3) · [RX8130CE 데이터시트](https://download.epsondevice.com/td/pdf/app/RX8130CE_en.pdf)

화면이 꺼지면 화면 갱신과 배터리 화면용 읽기를 중단하고, 조건이 맞으면 ESP32가 라이트 슬립에 들어갑니다. 효과음이 끝나면 오디오 전원을 끄며, 마우스 추적, 하프 연주 및 보정에 자이로를 사용합니다. 연결된 에어마우스의 동작과 EMS 타이머 알림은 유지됩니다. 배터리 소모를 비교할 때는 USB를 뽑고 홈에서 화면이 꺼진 뒤 같은 조건으로 측정합니다.

### 5. IR REMOTE (적외선 리모컨 학습)

홈 화면은 한 번에 메뉴 4개를 표시합니다. **A**는 다음, **A+B 짧게**는 이전, **B**는 열기입니다. 위·아래 삼각형은 해당 방향에 숨은 항목이 있을 때만 표시됩니다.

**IR REMOTE**에서 슬롯을 열고 **STANDARD** 또는 **EXTENDED**를 선택합니다. STANDARD는 원본 리모컨을 짧게 누릅니다. EXTENDED는 버튼을 눌러 여러 프레임과 그 사이의 간격을 기록합니다.

**TEST SEND**에서 36/38/40 kHz, NORMAL/HIGH, 한 번/캡처 순서/반복을 고릅니다. NEC로 식별된 단일 프레임은 표준 타이밍으로 시험할 수 있습니다. **Save settings**를 누르면 현재 슬롯에 신호와 설정을 저장합니다. 지원하는 기본 반송파가 38 kHz인 수신기에서는 다른 반송파의 원본이 정상적으로 학습되지 않을 수도 있습니다. 긴 발광 구간이나 빠른 연속 송신에는 NORMAL 세기를 사용합니다.

### 6. TIMER와 RECORDER

- 심플 **TIMER**에서 A를 짧게 누르면 시각을, 길게 누르면 시각과 음성 메모를 기록합니다. A를 다시 누르거나 10초가 지나면 녹음을 저장합니다. B로 시간 기록을 열어 마이크가 표시된 칸을 재생합니다.
- **RECORDER**는 A로 녹음·저장하고 B로 녹음 목록을 엽니다. 1개 클립은 최대 60초이며, 저장 공간에 따라 사용 가능한 길이가 줄어듭니다. 목록에서 클립을 열어 재생하거나 삭제합니다.
- 녹음은 8 kHz 모노 음성으로 저장되며, 마이크는 녹음 중에만 켜집니다. 녹음 중 EMS 알림이 오면 마이크를 끄고 녹음을 마무리합니다.

## 빌드 및 플래시 방법

이 저장소는 GitHub Actions에서 **ESP-IDF v5.3.1 (`esp32s3`)**으로 자동 빌드됩니다.

기존 기기에서 녹음 기능을 활성화하려면 처음 한 번 새 파티션 테이블(`0x8000`)도 앱과 함께 기록합니다. 기존 NVS와 OTA 앱 슬롯 주소는 동일합니다. 설정과 IR 슬롯을 보존하려면 보드 전체를 지우지 말고 파티션 테이블과 사용 중인 앱 슬롯만 업데이트합니다.

1. GitHub 저장소의 **Actions** 탭 → **Build StickS3 EMS & AirMouse Firmware** 실행 결과에서 `sticks3-ems-airmouse-<sha>` 아티팩트를 다운로드합니다.
2. 압축 해제 후 아래 명령으로 StickS3에 플래시합니다 (`COM번호` 또는 `/dev/ttyACM0` 확인).
   - **전체 통합 이미지 플래시 (권장 - 최초 설치)**:
     ```bash
     python -m esptool --chip esp32s3 --port COM번호 write-flash 0x0 sticks3-ems-airmouse-full.bin
     ```
   - 참고: `AIR MOUSE USB` 모드를 종료한 후 USB 시리얼 콘솔이 복구되지 않으면 `SETTINGS → Device → Reboot Device`로 재부팅하세요(펌웨어 재플래시용 다운로드 모드는 언제든 진입 가능).
